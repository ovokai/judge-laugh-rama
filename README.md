A one-line office joke for the make.fun competition **Make the AI Judge Laugh**:

> Our office printer only jams when the document is urgent — it's the only thing here that can smell a deadline.

[bounty page](https://make.fun/c/u-rama-melon-make-the-ai-judge-laugh-302d0825)

## Run

```sh
node main.ts
```

Writes the joke to `/output/entry.txt` (falls back to a local `entry.txt` when `/output` is not writable). Node standard library only, no dependencies.
